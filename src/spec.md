# Specification

## Summary
**Goal:** Implement comprehensive admin backend system with authentication, theme/page/pricing management, payment gateway integrations (Stripe, Razorpay, Coinbase Commerce, NOWPayments), payment dashboard, and make all dashboard modules fully functional with real backend integration. Redesign logo and upgrade UI to professional standards.

**Planned changes:**
- Add admin authentication system in backend with role-based access control
- Build admin theme management allowing color scheme and typography customization
- Implement admin page management for enabling/disabling pages and reordering navigation
- Create admin subscription pricing editor for updating plans without code changes
- Integrate four payment gateways (Stripe, Razorpay, Coinbase Commerce, NOWPayments) with admin API key configuration
- Build admin payment dashboard displaying all transactions with filtering and export
- Redesign application logo with professional, modern design
- Upgrade UI design throughout application with refined spacing, colors, typography, and animations
- Implement full backend functionality for Payouts module with CRUD operations
- Implement full backend functionality for Expenses module with categories and summaries
- Implement full backend functionality for Trading Overview with manual trade entry and statistics
- Complete all Tools page calculators (Risk, Margin, P/L, Lot Size, Swap) with real-time calculations
- Implement Reviews & Disputes module with backend storage and submission history
- Complete Compounding calculator with growth chart and breakdown table
- Implement Income Tax Calculator with country-specific tax brackets and quarterly estimates
- Complete FX and Crypto exchange converters with real-time rates

**User-visible outcome:** Admins can log in through the backend to manage themes, pages, pricing, and payment gateways with secure API key configuration. Payment transactions display in real-time admin dashboard. All dashboard modules (Payouts, Expenses, Trading Overview, Tools calculators, Reviews & Disputes, Compounding, Tax Calculator, Exchange converters) are fully functional with backend integration. Application has professional new logo and polished UI design throughout.
